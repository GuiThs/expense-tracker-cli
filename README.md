# Expense Tracker CLI

A simple but robust Python CLI application to track personal expenses.
This project focuses on clean data handling, user input validation, and basic data analysis logic.

## Features
- Add expenses with validation
- Delete existing expenses
- View all expenses in a readable format
- Display total expenses
- Persistent file-based storage

## Project Goals
- Practice Python fundamentals (functions, loops, conditions)
- Handle user input safely
- Work with file I/O (read / write)
- Normalize and process structured data
- Build a clean and maintainable CLI application

## Tech Stack
- Python 3
- Standard Library only (no external dependencies)

## How It Works
Expenses are stored in a text file using a structured format.
The application follows a simple data pipeline:
- Load expenses from file
- Process data in memory
- Save updated data back to file

## Possible Improvements
- Add advanced statistics (average, min/max, category breakdown)
- Export data to CSV
- Add date validation
- Improve CLI UX
